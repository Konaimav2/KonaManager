# KonaManager rebuild: PLAN

Planner: manager-1. Repo target `Konaimav2/KonaManager` (public). Module id stays `daemon-manager`; only `name=KonaManager - Simple Daemon Manager` changes. Pipeline: Planning > DESIGN > Backend + UI > QA > Judge (fable, dispatched by manager-1, outside the executor list) > DevOps.

## 1. Objective, non-goals, assumptions
**Objective:** rebuild dm + WebUI so daemon state is verified (not assumed), AppGuard is fully configurable, daemons can be installed/created/imported/deleted safely from the UI, and the live install updates in place from a zip with data preserved.
**Non-goals:** no PRD.md/DESIGN.md now (DESIGN.md is task T1); no commit/push/deploy without an explicit verb; no new daemons; no Termux/sshd changes; no per-user NEVER lists; no remote package index.
**Assumptions (A#) verified by `dm doctor` / T9 probe:**
- A1 root `sh` is Android mksh/toybox with no `jq` or `python`. JSON is emitted with printf and an escape helper; JSON input arrives as base64 of `key=value` lines, never parsed as JSON or sourced.
- A2 `curl` or busybox `wget` and `unzip`, `sha256sum`, `base64` exist (KSU busybox `/data/adb/ksu/bin/busybox`, or Termux curl as fallback). If missing, install stage fails with `E_NO_TOOL` and `dm doctor` says which.
- A3 Live paths: data `/data/adb/daemon-manager`, AppGuard `/data/adb/appguard`, `service.d` scripts `/data/adb/service.d`, root sshd `/data/adb/sshd` (root.pid, sshd_config), SIM monitor `/data/adb/sim-monitor`. Module dir `/data/adb/modules/daemon-manager`.
- A4 Source facts found: sources are under `daemon-manager/` (not the repo root); the old UI calls `dm` by two different paths (data dir in SPEC-webui, module dir in SPEC-webui-settings); `service-wifi-ps-guard.sh` and `service-wifi-tune.sh` are mode 644 in the live copy (= currently disabled) and must not be flipped by migration; `wifi-ps-guard` backgrounds a subshell and exits, so its launcher PID dies at once (pidfile alone is wrong for it).
- A5 AppGuard fact: U999 holds `com.whatsapp com.discord id.dana` but NEVER also holds `com.whatsapp com.discord`, so today only `id.dana` is ever killed in user 999. Migration keeps all 3 as u999 targets plus the NEVER list unchanged; UI shows a "blocked by Never" chip. Behavior is identical on day one; the user can unblock later.
- A6 `ksu.exec(cmd, callbackName)` is blocking per call with a string global callback; stdout is only returned at exit.

## 3. Data / config schema (`R=/data/adb/daemon-manager`, all additive; nothing old is rewritten)
- `R/schema_version` (`2`), `R/dm.log` (rotate at 1000 lines), `R/jobs/<id>.json`, `R/staging/<token>/` (swept after 1h), `R/rollback/<oldver>/` (old bin, webroot, module.prop, daemons.conf, appguard.sh), `R/backups/<ts>.tar` (keep 3), untouched: `R/deep-sleep-cool.conf`.
- **Daemon dir** `R/daemons/<id>/`: `meta` (key=value, whitelisted keys, parsed with grep/cut, never sourced), `start.sh`, `stop.sh?`, `hooks/{install,uninstall}.sh?`, `files/`, `daemon.pid`, `daemon.log`, `last` (`ts action ok code`). Builtins use `meta` only (scripts stay where they are).
- **meta keys:** `id` (`^[a-z0-9][a-z0-9-]{1,30}$`), `name`, `desc`, `version`, `kind=daemon|oneshot`, `source=builtin|package|created|imported`, `start` (abs path, or relative inside own dir), `stop` (abs/relative path or `cmd:<one line>`, optional), `pidfile`, `argv_match` (exact argv element, e.g. `/data/adb/sshd/sshd_config`), `stop_scope=marker|pidfile` (default marker; root-sshd = pidfile so live root sessions survive), `start_timeout=8`, `stop_grace=5`, `health=proc|port:<n>|cmd:<path>|heartbeat:<file>:<max_s>`, `boot=xbit|wrapper`, `boot_wait=0|1`, `removable=0|1` (builtins 0 = "unmanage" only), `enabled_hint`.
- **Enabled** = boot entry is executable: builtin/imported `boot=xbit` (the service.d script's x-bit, unchanged so KSU still boots them with no dm in the path); package/created `boot=wrapper`: `/data/adb/service.d/km-<id>.sh`, x-bit = enabled, fixed template, line 2 `# km-managed:<id>`: `[ -x $DM ] || exit 0; [ boot_wait ] && wait boot_completed; exec $DM boot <id>`. `$DM=/data/adb/modules/daemon-manager/bin/dm`.
- **Process marker:** every start exports `KM_DAEMON_ID=<id>` (inherited by children). Boot wrappers go through `dm boot` so they carry it; xbit boots do not, hence the pidfile + exact-argv fallback (reported as `verified_by`).
- **AppGuard** `R/appguard/`: `appguard.conf` (`INTERVAL=60 COOLDOWN=300 DRY=0 CFGVER=n`), `targets.tsv` (`pkg<TAB>u0<TAB>u999<TAB>cooldown_s`, blank cooldown = global), `never.list` (one pkg per line), `kills.tsv` (`epoch user pkg mode result cooldown reason`, cap 500), `heartbeat` (touched each sweep, contains `AG_VERSION`). Cooldown stamps stay in `/data/adb/appguard/cool/`. Loops re-read config every sweep (no restart for config changes).
- **Package zip (`.zip`, <=5 MiB, <=200 entries):** root `daemon.json`-equivalent `daemon.meta` (the meta keys above + `schema=1`, `min_dm`, `hooks.install.sha256`, `hooks.uninstall.sha256`), `start.sh`, optional `stop.sh`, `hooks/install.sh`, `hooks/uninstall.sh`, `files/**`. Rules: names match `^[A-Za-z0-9._/-]+$`, no leading `/`, no `..` segment, no `\`, no symlinks/devices (checked via `unzip -l` before and `find ! -type f ! -type d` after extract), `id` not in use and not builtin, every path in meta resolves inside the staging dir, hook hashes match, HTTPS only (no downgrade on redirect), optional pinned sha256 for the whole zip.
- **Created daemon:** UI sends `b64(name=\nkind=\nstart=\nstop=\n)`; dm slugs the id, writes `start.sh` via a quoted heredoc (nothing is interpolated into a shell string), `sh -n` checks it. Limits: start/stop single line, <=1024 chars, no NUL.
- **Import:** only a regular, non-symlink file directly in `/data/adb/service.d/`, name `^[A-Za-z0-9._-]+\.sh$`, not already managed; writes `meta` with `source=imported boot=xbit removable=1`; the script is never moved, edited or deleted.

## 4. `dm` command contract
Every command prints exactly one JSON object on stdout, stderr empty, exit 0 on `ok:true`, 1 on `ok:false`, 2 on usage. Errors: `{"ok":false,"code":"E_*","msg":"..."}` with codes `E_USAGE E_UNKNOWN E_BUSY E_ARG E_NOT_ROOT E_NO_SCRIPT E_START_TIMEOUT E_START_EXITED E_STOP_STILL_RUNNING E_NO_TOOL E_DOWNLOAD E_VERIFY E_PATH E_CONFLICT E_HOOK E_NOT_REMOVABLE E_CONFIRM`. Free text only ever travels as base64. Per-id mutating commands take a `flock`-style lock dir `R/lock/<id>` (`E_BUSY` if held).
**Daemon object `D`:** `{"id","name","desc","kind":"daemon|oneshot","version","source","enabled":bool,"state":"running|stopped|failed|done|unknown","running":bool,"pid":int|null,"pids":[int],"uptime_s":int|null,"health":"ok|degraded|down|na","health_detail":"","verified_by":"marker|pidfile+argv|none","removable":bool,"boot":"xbit|wrapper","last":{"action","ts","ok","code"}|null}`
- `list` > `{"ok":true,"dm":"2.0.0","schema":2,"ts":int,"daemons":[D...]}` (one shared `/proc/*/environ` scan per call; pidfile fast path first)
- `status <id>` > `{"ok":true,"daemon":D,"meta":{...},"exit_code":int|null,"log_tail":["..."]}`
- `start <id>` > `{"ok":true,"id","action":"start","state":"running","pid":int,"pids":[int],"uptime_s":int,"waited_ms":int,"already":bool,"msg":"started"}`; oneshot > `state:"done","exit_code":0`; fail > `{"ok":false,"code":"E_START_TIMEOUT|E_START_EXITED","msg","waited_ms","state","exit_code"}`
- `stop <id>` > `{"ok":true,"id","action":"stop","state":"stopped","steps":["stop_cmd","TERM","KILL"],"killed_pids":[int],"waited_ms":int}`; fail > `{"ok":false,"code":"E_STOP_STILL_RUNNING","pids":[int],"msg"}`
- `enable <id>` / `disable <id> [--keep-running]` > `{"ok":true,"id","enabled":bool,"boot":"xbit|wrapper","stopped":bool,"msg"}` (disable stops via `stop`, so it can fail with E_STOP_STILL_RUNNING and leaves enabled state changed)
- `boot <id>` (wrapper entry) > same as `start`. `restart <id>` = stop + start, returns `{"ok","stop":{...},"start":{...}}`.
- `install stage <https-url|/abs/path.zip> [sha256]` > `{"ok":true,"job":"j_ab12"}`; `job <id>` > `{"ok":true,"job","state":"running|done|failed","step":"download|verify|extract|validate","pct":int,"result":null|P,"code"?,"msg"?}`, where `P={"token":"t_ab12","manifest":{id,name,version,kind,desc,start,stop},"hooks":{"install":{"sha256","bytes","preview":["first 40 lines"]}|null,"uninstall":{...}|null},"files":int,"bytes":int,"sha256","conflict":"none|exists|builtin","warnings":[]}`.
- `install commit <token> --confirm <id>` > `{"ok":true,"id","version","dir":"R/daemons/<id>","hook":{"ran":bool,"exit":int|null},"enabled":false}`; `install abort <token>` > `{"ok":true}`. No stage output ever runs before commit.
- `delete <id> --plan` > `{"ok":true,"plan":{"stop":bool,"remove_dir":"R/daemons/<id>"|null,"remove_wrapper":"/data/adb/service.d/km-<id>.sh"|null,"run_uninstall_hook":bool,"keeps":["paths left alone"]}}`; `delete <id> --confirm <id>` > `{"ok":true,"id","stopped":bool,"hook":{"ran","exit"},"removed":["path"],"unmanaged":bool}`. Builtins/imported: only `meta` and the km wrapper go; `E_NOT_REMOVABLE` for removal of files outside `R/daemons/<id>/`.
- `create <b64kv>` > `{"ok":true,"id","dir","enabled":false}`
- `import list` > `{"ok":true,"candidates":[{"path","name","executable":bool,"managed":bool,"bytes":int}]}`; `import <path> <b64kv(name,kind,stop?)>` > `{"ok":true,"id","script","enabled":bool,"source":"imported"}`
- `logs <id|dm|appguard> [n<=200]` > `{"ok":true,"source","lines":["..."],"truncated":bool}`
- `appguard get` > `{"ok":true,"config":{"interval_s":60,"cooldown_s":300,"dry_run":false},"never":["pkg"],"targets":[{"pkg","u0":bool,"u999":bool,"cooldown_s":int|null,"shadowed":bool}],"counts":{"targets":33,"u0":30,"u999":3,"never":6},"daemon":D,"running_version":"x","installed_version":"x"}`
- `appguard set interval|cooldown|dry <v>` (10..3600 / 0..86400 / 0|1) > `{"ok":true,"key","value":int,"msg":"saved"}`
- `appguard targets list` > `{"ok":true,"targets":[...]}`; `... add <pkg> [u0=1 u999=0 cooldown=N]`, `... set <pkg> u0=.. u999=.. cooldown=..|default`, `... rm <pkg>` > `{"ok":true,"pkg","u0","u999","cooldown_s"}`; `appguard never list|add|rm <pkg>` > `{"ok":true,"never":["pkg"]}`; pkg regex `^[A-Za-z0-9_.]+$`, length <=128.
- `appguard packages [--user 0|999] [--q <substr>]` > `{"ok":true,"user":0,"packages":[{"pkg","target":bool,"never":bool}]}` (`pm list packages -3 --user N`)
- `appguard kills [limit<=200]` > `{"ok":true,"total":int,"kills":[{"ts","user","pkg","mode":"kill|dry","result":"ok|fail","cooldown_s","reason"}]}`
- `appguard once [--dry]` > `{"ok":true,"dry":bool,"sweep":{"skipped":null|"foreground-unknown","candidates":int,"killed":int,"would_kill":[{"user","pkg"}],"skipped_fg":["pkg"],"skipped_cooldown":int},"ms":int}`
- Compat kept: `getconf`, `setconf freeze_unplugged 0|1`, `whitelist list|add|rm|set`, `packages`, `version` > `{"version":"2.0.0","schema":2}`. New: `doctor` > `{"ok":true,"root":bool,"tools":{"curl":"path|null","unzip":..,"sha256sum":..,"base64":..,"pm":..},"selinux":"..","writable":bool}`; `migrate [--dry-run]` > `{"ok":true,"from":1,"to":2,"actions":["..."],"counts":{"targets":33,"never":6}}`; `rollback` > `{"ok":true,"restored":"1.0"}`.

## 8. Risks and fallbacks
- **Install security** (root code from the network): HTTPS-only, size/entry caps, zip-slip checks before AND after extract, no symlinks, hooks hash-pinned and shown in full in the confirm step with "runs as root" text, hooks run with a 30s timeout and cwd in the daemon dir, nothing executes before commit, delete only removes `R/daemons/<id>/` after `readlink -f` prefix check and refuses if the dir is a symlink. Fallback: if `unzip` is absent use busybox; if none, local path install is disabled and `E_NO_TOOL` is shown.
- **User 999**: `am kill --user 999` may be refused on some ROMs; user-999 recents are not exposed so only foreground protects it. Result is logged `fail` and the cooldown still applies (no spam). `once --dry` is the first acceptance step; whatsapp/discord u999 stay shadowed by NEVER (A5).
- **Process verification**: `environ` reflects exec-time env only, so `env -i` or sanitising daemons (sshd) drop the marker; fallback is pidfile + exact argv element. Zombies are rejected. Scans are shared per call to keep `list` fast; target <500 ms with 6 daemons. A bad pidfile never causes a signal to an unverified pid.
- **Boot wrappers**: xbit boots (builtins) have no marker; they stay so a broken dm cannot stop boot. Wrapper no-ops if the module is gone. Double start is prevented by `already` detection. Enabled state lives only in the x-bit, so there is no second source of truth.
- **Live update rollback**: additive migration, backups in `R/backups`, old module and `appguard.sh.pre-km` in `R/rollback`; running daemons are not restarted by the update, so AppGuard keeps the old lists until restarted (UI shows `running_version != installed_version` and a "restart to apply" hint). `dm rollback` or flashing the old zip restores the previous state. Never replace a running shell script in place.
- **UI bridge limits**: callback is blocking and returns stdout only at exit, so downloads and anything over a few seconds run as jobs polled every 1s; keep output under ~64 KB (log tail cap 200 lines); the command string is the injection surface, so only validated tokens/base64 are interpolated; duplicate in-flight calls are de-duplicated; concurrency capped at 3.
- **CSP**: strict policy may block the manager's own WebView injections; test in the real KSU WebUI (T9). Fallback: allow `style-src 'unsafe-inline'` only if verified necessary, recorded as a deviation. Inline styles are avoided by classes and CSSOM.
- **Public repo hygiene**: no real package lists, tokens or IPs in tracked files; seeds live in gitignored `local/`.
- **Termux/sshd**: root sshd `stop_scope=pidfile` kills only the listener recorded in `root.pid`; no automated test ever runs stop on `root-sshd`.
